# Motywy z konfiguratora wyglądu

Jeden plik `<nazwa>.json` na motyw — konfig pobrany z konfiguratora wyglądu.
Task Grunta `motywy` kompiluje go do `../app-<nazwa>.css`, a motyw pojawia się
w adminie uczelni (`BPP_THEMES`) bez żadnej dodatkowej rejestracji.

Opis: `docs/deweloper/budowanie-css.md`, sekcja „Motywy z konfiguracji”.

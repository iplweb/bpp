„Import z PBN” (menu „PBN” → „Import z PBN”, krok importu publikacji) tworzy teraz rekordy z **wersji przypiętej na profilu instytucji** w PBN, a nie z wersji bieżącej w repozytorium PBN. Dotąd, jeśli ktoś spoza uczelni zmienił pracę w repozytorium PBN (tytuł, autorów, strony), do BPP trafiały jego dane zamiast wersji zatwierdzonej przez uczelnię.

Jeśli profil instytucji nie wskazuje wersji albo wskazanej wersji nie ma w pobranych danych, import bierze — jak dotąd — wersję bieżącą i zapisuje w logu sesji importu ostrzeżenie „Prace z profilu instytucji: … wzięto z wersji przypiętej na profilu, … z wersji bieżącej” z listą identyfikatorów takich prac, żeby można je było sprawdzić. Prace spoza profilu instytucji (np. książki nadrzędne rozdziałów) importują się bez zmian, z wersji bieżącej. Zmiana dotyczy tylko rekordów tworzonych od teraz — rekordów już zaimportowanych import nie zmienia. Import pojedynczej pracy importerem publikacji działa jak dotąd.

Dane Open Access monografii i rozdziałów (tryb dostępu, licencja, wersja tekstu, czas udostępnienia) są teraz wysyłane do PBN — wcześniej blok ``openAccess`` był pomijany dla wszystkich wydawnictw zwartych (FD#281). Rekordy wysłane do PBN przed tą poprawką nie mają tam danych OA, dopóki nie zostaną wysłane ponownie. Aby je odnaleźć: Wprowadzanie danych → Wydawnictwa zwarte, włącz wyszukiwanie DjangoQL (przełącznik przy polu wyszukiwania) i wpisz ``pbn_uid != None and openaccess_tryb_dostepu != None and openaccess_licencja != None and openaccess_wersja_tekstu != None and openaccess_czas_publikacji != None`` (rekordy już obecne w PBN, z kompletem danych OA). Aby wysłać je zbiorczo: zaznacz wszystkie wyniki („Zaznacz wszystkie …”) i wybierz akcję „Wyślij do PBN w tle” — rekordy trafią do kolejki eksportu (postęp: PBN API → Kolejka eksportu). Jednorazowo można zakolejkować do 2000 rekordów; przy większej liczbie zawęź wyniki filtrem „rok” i powtórz dla kolejnych lat.

Wzmocniono zabezpieczenia logowania przez Microsoft (Office 365): wymagane jest wskazanie konkretnego katalogu Entra ID (``MICROSOFT_AUTH_TENANT_ID``), weryfikowane są claimy ``iss``/``tid`` tokenu, a nowe konto Microsoft nie jest automatycznie wiązane po adresie e-mail z istniejącym kontem administracyjnym lub posiadającym hasło lokalne (chyba że ``MICROSOFT_AUTH_LINK_BY_EMAIL=True``).

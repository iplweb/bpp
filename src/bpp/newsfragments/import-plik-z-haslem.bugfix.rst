Import danych z POL-on i import absencji: wgranie pliku Excel zabezpieczonego hasłem kończy się teraz zrozumiałym komunikatem „Plik jest zabezpieczony hasłem. Wpisz hasło w polu „Hasło do pliku” albo otwórz plik w Excelu, usuń hasło (…) i wgraj go ponownie.” zamiast niezrozumiałego „Błąd podczas odczytu nagłówków: Can't find workbook in OLE2 compound document”, a taki przypadek nie jest już zgłaszany jako błąd aplikacji. Pozostałe importy z plików Excel (m.in. import pracowników, import dyscyplin, import punktacji źródeł, list ministerialnych) również rozpoznają plik z hasłem i pokazują komunikat z instrukcją, jak zdjąć hasło w Excelu — import pracowników nie próbuje już czytać takiego pliku jako CSV.
